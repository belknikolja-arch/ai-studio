# ИИ-Студия

Одностраничное приложение в **одном файле** `index.html` — единый чат, который может **всё**:
болтать (LLM), **генерировать фото**, **писать музыку** и **говорить голосом**.

- Работает локально, без сервера: запросы из браузера идут напрямую к провайдерам
- **Ключи API вводятся в настройках и хранятся только в localStorage** этого браузера
- Роутинг команд детерминирован: «нарисуй …» → фото, «сделай песню …» → музыка, «произнеси …» → голос, остальное → чат
- Тёмная/светлая тема, история чата в localStorage, адаптивная вёрстка
- Дисклеймер: контент генерируют сторонние модели (OpenAI / Anthropic / Google / Replicate); ключи платные или с бесплатным тарифом — зависит от провайдера

## Команды в чате

| Что напишете | Что произойдёт |
|---|---|
| `нарисуй …`, `сгенерируй фото …`, `изобрази …` | генерация картинки |
| `сделай песню …`, `сгенерируй музыку …`, `напиши трек …` | музыкальный трек (Replicate MusicGen) |
| `произнеси …`, `озвучь …`, `прочитай вслух …` | озвучка (веб-режим — без ключей!) |
| всё остальное | обычный ответ LLM |

## Провайдеры

**Чат (текст):**
- **OpenAI** (`sk-…`, [platform.openai.com/api-keys](https://platform.openai.com/api-keys)) — gpt-4o-mini / gpt-4o / gpt-4.1…
- **Anthropic** (`sk-ant-…`, [console.anthropic.com](https://console.anthropic.com)) — claude-sonnet-4…
- **Google Gemini** (`AIza…`, [aistudio.google.com/apikey](https://aistudio.google.com/apikey), есть бесплатный тариф) — gemini-2.5-flash…

**Фото:**
- **OpenAI** — gpt-image-1 / dall-e-3 (b64, размер на выбор)
- **Google** — gemini-2.5-flash-image / imagen (b64)
- **Replicate** (`r8_…`, [replicate.com/api/tokens](https://replicate.com/api/tokens), есть бесплатные минуты) — flux-1.1-pro / flux-schnell / sdxl и любые другие (модель вписывается свободно)

**Музыка:** Replicate — meta/musicgen-large (10/20/30 с) и другие модели по вашему выбору.

**Голос:**
- **Веб-озвучка браузера** (Web Speech API) — бесплатно, без ключей, работает офлайн
- **OpenAI TTS** (tts-1) — mp3, голоса alloy/echo/fable/onyx/nova/shimmer

Модели везде вписываются свободно (с подсказками), так что приложение переживёт смену версий API.

## Как это работает

1. Текст сообщения идёт в ядро `routeIntent()` — детерминированный разбор команд.
2. По типу намерения вызывается провайдер:
   - чат — `POST /chat/completions` (OpenAI), `/v1/messages` (Anthropic), `:generateContent` (Gemini);
   - фото — `/v1/images/generations` (OpenAI), `:generateContent` (Gemini), `Replicate predictions` (опрос статуса до 5 минут);
   - музыка — Replicate predictions (аудио-URL);
   - голос — `speechSynthesis` браузера или `/v1/audio/speech` (OpenAI).
3. Результат (текст / dataURL / URL) добавляется в чат и сохраняется в историю (картинки — до 6 шт., дальше только ссылки).

## Технологии

- Один `index.html`: HTML + CSS + JS, без фреймворков и зависимостей.
- Ядро — чистые JS-функции без DOM (роутинг, тела запросов, парсинг Replicate, трим истории).
- Форматирование и логика детерминированные, ядро покрыто тестами (34 проверки в Node).
