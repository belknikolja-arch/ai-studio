# 🎛 ИИ-Студия (ai-studio) — v1.1, React + Vite

Репозиторий: **https://github.com/belknikolja-arch/ai-studio**

Одно окно на всё: **чат с LLM**, **генерация фото**, **музыка** и **озвучка текстов**.
Скомандуйте «нарисуй …», «сделай песню …» или «произнеси …» — остальное разберётся само.

- **Кроссплатформенно**: это обычный веб-проект (React 18 + Vite 5), работает в любом современном браузере на любой ОС (Windows / macOS / Linux / Android / iOS).
- **Свои ключи API**: OpenAI, Anthropic (Claude), Google (Gemini), Replicate. Ключи хранятся **только в localStorage вашего браузера** и никуда не отправляются, кроме самого провайдера. Сервера нет.
- **Бесплатный голос без ключей**: веб-озвучка браузера (speechSynthesis) работает сразу.

## Быстрый старт

Требуется **Node.js 18+** (рекомендуется 20+).

```bash
npm install     # зависимости
npm run dev     # режим разработки → http://localhost:5173
npm test        # проверки ядра (node --test, без браузера)
npm run build   # production-сборка → dist/
npm run preview # посмотреть production-сборку локально
```

Структура:

```
index.html            — оболочка Vite (точка входа)
vite.config.js        — настройки Vite
src/
  main.jsx            — монтирование React
  App.jsx             — чат, отправка, тема
  config.js           — настройки по умолчанию, localStorage
  styles.css          — стили (тёмная/светлая тема)
  core/               — ЧИСТОЕ ядро (без DOM/fetch) — тестируется в Node
    intents.js        — роутинг команд: нарисуй/сделай песню/произнеси/чат
    providers.js      — тела запросов OpenAI/Anthropic/Gemini/Replicate
    history.js        — обрезка истории (≤40 сообщений, ≤6 data: медиа)
    voices.js         — выбор голоса, определение языка
  api/index.js        — браузерный слой: fetch к провайдерам, озвучка
  hooks/              — useSettings, useHistory (localStorage)
  components/         — Message, SettingsPanel, CommandHints, HelpKeys
tests/
  core.test.js        — 59 проверок ядра (npm test)
```

## Команды в чате

| Начните фразу | Что сделает |
|---|---|
| `нарисуй …` / `сгенерируй фото …` / `изобрази …` | картинка (OpenAI gpt-image-1, Gemini image или Replicate/Flux) |
| `сделай песню …` / `сгенерируй музыку …` / `напиши трек …` | музыка (Replicate MusicGen, 5–30 с) |
| `произнеси …` / `озвучь …` / `прочитай вслух …` | голос (веб-режим — без ключей; или OpenAI TTS mp3) |
| всё остальное | обычный разговор с LLM |

## Ключи API (вставить в «Настройки» справа)

| Провайдер | Что умеет | Где взять ключ |
|---|---|---|
| OpenAI | чат, фото, TTS-голос | https://platform.openai.com/api-keys — `sk-…` (нужна оплата) |
| Anthropic | чат (Claude) | https://console.anthropic.com/settings/keys — `sk-ant-…` |
| Google Gemini | чат и фото | https://aistudio.google.com/apikey — `AIza…` (есть бесплатный тариф) |
| Replicate | фото (Flux), музыка (MusicGen) | https://replicate.com/api/tokens — `r8_…` (есть бесплатные минуты) |

Пустое поле = провайдер выключен. Если все ключи пусты, работает только веб-озвучка.

## Публикация (GitHub Pages)

Приложение собирается в статические файлы в `dist/`. Для GitHub Pages:

```bash
npm run build
# содержимое dist/ положить на ветку gh-pages (или в корень ветки Pages)
```

Сборка самодостаточная (без внешних CDN), работает по адресу
`https://<логин>.github.io/ai-studio/` без дополнительной настройки.

## Частые вопросы

- **«Нужен ключ OpenAI, а у меня 0 кредитов?»** — добавьте кредиты в billing аккаунта OpenAI, либо используйте бесплатный ключ Gemini (чат + фото) и веб-озвучку без ключей.
- **Фото/музыка генерируются долго?** — нормально: Replicate опрашивает статус каждые 2.5 с, до 5 минут.
- **Куда сохраняются картинки?** — в истории чата (localStorage). Ссылки провайдеров могут истечь после перезапуска — просто сгенерируйте заново.
- **Мой контент виден провайдеру?** — да: запрос с вашим промптом уходит напрямую к выбранному провайдеру.
